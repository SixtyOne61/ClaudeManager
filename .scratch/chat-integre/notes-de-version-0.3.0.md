Claude Manager devient un client complet de Claude Code : on discute avec l'agent directement dans l'app.

**Discuter dans l'app**
- Chaque conversation s'ouvre dans un onglet. Le vrai Claude Code tourne dans un terminal intégré, caché derrière une vue de la conversation.
- Vos messages, les réponses de Claude et ses actions sont bien distincts. Les actions sont repliées en une ligne, dépliable au clic.
- Taper `/` propose les commandes, vos skills et ceux de vos plugins.
- En bas de la conversation : le modèle, le mode de permission et le contexte utilisé.
- Le terminal apparaît de lui-même quand Claude Code demande une permission ou pose une question. Claude Manager ne valide jamais rien à votre place.

**Suivre et organiser**
- Une pastille indique l'état de chaque conversation : en cours, action requise, à toi.
- Vos limites d'utilisation (5 h et semaine) en bas de la barre latérale.
- Des sections dans chaque projet, des couleurs par conversation, la sélection de plusieurs conversations à la fois.
- Les conversations des worktrees sont rangées sous leur projet.
- Recherche dans le contenu de toutes les conversations (Ctrl+Maj+F).
- Nouvelle conversation dans l'app, au choix dans un nouveau worktree.

Connexion : Claude Manager lance Claude Code tel qu'Anthropic le fournit, avec votre propre abonnement. L'app ne lit ni ne transmet vos identifiants, et ne modifie pas vos réglages.
