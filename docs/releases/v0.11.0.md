Claude Manager parle maintenant votre langue, et les hubs, les sections et les réglages sont réorganisés.

Langue
- Dans Réglages, onglet Langue, tapez le nom d'une langue : Claude traduit toute l'interface avec votre abonnement, et la traduction est gardée.
- Les langues déjà traduites se choisissent ou se suppriment d'un clic ; après une mise à jour de l'application, seuls les nouveaux textes sont traduits.

Réglages
- Les réglages sont rangés en onglets sur la gauche : Affichage, Suggestions, Hand off, Langue.

Suggestions
- Quand vous recommencez à écrire dans une conversation inactive depuis longtemps et au contexte chargé, un bandeau prévient que le prochain message fera relire tout le contexte et propose un hand off. La durée et le seuil se règlent.
- Pendant la rédaction du résumé d'un hand off, le bouton Arrêter annule le hand off.

Hubs
- Les hubs ont leur propre onglet dans la barre latérale, à côté de Projets et Conversations.
- Cliquer un hub l'affiche dans la zone principale, comme un projet ; un membre se glisse d'un hub à l'autre.

Sections
- « Sans section » devient la section Général : elle se renomme, se colore et se déplace comme les autres.
- Une case dans l'en-tête d'une section sélectionne toutes ses conversations.

Conversation
- Les séries de questions affichent les numéros avec suffixe, comme Q1b.
