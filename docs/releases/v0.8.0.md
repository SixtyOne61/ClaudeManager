Claude Manager arrive sur macOS, pour les Mac Intel comme Apple Silicon.

macOS
- Installez l'application depuis le fichier .dmg de la release, puis autorisez-la une fois dans Réglages Système, Confidentialité et sécurité.
- Claude Code est trouvé comme dans votre terminal, même quand l'application est lancée depuis le Finder ou le Dock.
- Le terminal externe s'ouvre dans iTerm2 s'il est installé, sinon dans Terminal.
- Le dossier d'un projet s'ouvre dans le Finder, et les conversations supprimées vont dans la Corbeille de macOS.
- Les raccourcis utilisent la touche Commande : Commande+Maj+F pour la recherche, Commande+Entrée pour envoyer les réponses à une série de questions.
- Les mises à jour se font depuis l'application, comme sous Windows.
