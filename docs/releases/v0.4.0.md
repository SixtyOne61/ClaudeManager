Conversation
- Les blocs de commande des réponses de Claude (PowerShell, cmd, bash) ont un bouton ▶ : la commande s'exécute dans le dossier de la conversation, dans un petit terminal qui s'ouvre sous le bloc, avec Arrêter et Relancer.
- Clic droit sur ▶, ou le bouton fenêtre à côté : la commande s'exécute dans un terminal externe, qui reste ouvert ensuite.
- Rien ne s'exécute sans votre clic. Les commandes bash demandent Git pour Windows.
- Les liens des réponses s'ouvrent dans votre navigateur.
- Nouvelle conversation : le terminal ne s'affiche plus que si Claude Code demande s'il peut faire confiance au dossier.
