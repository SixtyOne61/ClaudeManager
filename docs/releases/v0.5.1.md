Répondez plus facilement aux séries de questions de Claude, corrigez un message avant qu'il ait répondu, et changez de modèle sans ouvrir le terminal.

Conversation
- Quand Claude pose plusieurs questions d'un coup (mode « grill »), elles s'affichent en cartes numérotées, avec sa recommandation mise en valeur.
- Un formulaire remplace la zone de saisie : pour chaque question, D'accord (accepte la recommandation), Non ou Autre réponse, plus un commentaire général. Envoyer n'est possible qu'une fois toutes les questions répondues.
- Dans votre message, chaque réponse porte une pastille Q1, Q2… : un clic ramène à la question correspondante.
- Les réponses commencées sont gardées si vous changez d'onglet. Un lien permet de répondre en texte libre à la place.
- Le dernier message peut être modifié tant que Claude n'a pas commencé à répondre : l'agent est interrompu et repart sur la nouvelle version. Les actions déjà faites ne sont pas annulées, l'app vous le signale.
- Le modèle se choisit dans un petit menu sous la zone de saisie (Opus, Sonnet, Haiku, variantes 1M de contexte), sans ouvrir le terminal.
- Le modèle affiché est mis à jour dès que vous en changez, sans attendre le message suivant.
